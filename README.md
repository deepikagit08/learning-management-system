#LevelUP LMS Admin Dashboard
A web-based admin dashboard concept for an Online Learning Management System (LMS). The interface includes sections for user management, course management, performance analytics, system settings, and activity monitoring.

## Technologies
- HTML
- CSS
- JavaScript

## How to run
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

This is a front-end dashboard. The data shown in the interface is currently sample/demo data unless additional backend code is added.
